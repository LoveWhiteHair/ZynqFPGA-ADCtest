#### 5. **UDP 服务器并发处理**

```python
def udp_server_concurrency(self) -> None:
    """
    用于创建一个线程持续监听UDP通信
    """
    while True:
        total_bytes_info = b''
        total_info = ''
        self.num_cnt = 0

        while self.num_cnt < self.data_byte:
            recv_msg, recv_addr = self.udp_socket.recvfrom(1024)
            info = recv_msg.hex()
            bytes_info = bytes.fromhex(info)
            rx_num_once = len(bytes_info)
            self.num_cnt += rx_num_once
            total_bytes_info += bytes_info
            total_info += info

        self.int_info = []
        for i in range(0, len(total_bytes_info), 4):
            four_bytes = total_bytes_info[i:i + 4]
            temp_int = struct.unpack('<I', bytes(four_bytes))[0]
            self.int_info.append(temp_int)

        self.plot_signal_data_info.emit(self.int_info)
        self.num_cnt = 0
```

- **功能**：持续监听 UDP 数据，接收并处理数据。
- **说明**：
  - 接收数据并累加，直到达到指定的字节数。
  - 将接收到的字节数据转换为整数列表。
  - 发送处理后的数据到 GUI。

```python
def udp_client_start(self, ip: str, port: int) -> None:
    """
    确认UDP客户端的ip及地址
    """
    self.udp_socket = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    self.udp_socket.bind(("", 9000))
    self.send_address = (ip, port)
    msg = "UDP客户端已启动\n"
    self.udp_signal_write_msg.emit(msg)
```

- **功能**：启动 UDP 客户端，绑定本地端口并设置目标地址。
- **说明**：创建 UDP 套接字并绑定到本地端口，设置目标 IP 和端口。

#### 7. **UDP 数据发送**

```python
def udp_send(self, send_info: str) -> None:
    """
    功能函数，用于UDP客户端发送消息
    """
    try:
        send_info_encoded = send_info.encode("utf-8")
        self.udp_socket.sendto(send_info_encoded, self.send_address)
        msg = "UDP客户端已发送"
        self.udp_signal_write_msg.emit(msg)
    except Exception as ret:
        msg = "发送失败\n"
        self.udp_signal_write_msg.emit(msg)
```

- **功能**：发送数据到目标地址。
- **说明**：将字符串编码为字节并发送到目标地址。

#### 8. **关闭 UDP 连接**

```python
def udp_close(self) -> None:
    """
    功能函数，关闭网络连接的方法
    """
    if self.link_flag == self.ServerUDP:
        try:
            self.udp_socket.close()
            msg = "已断开网络\n"
            self.udp_signal_write_msg.emit(msg)
        except Exception as ret:
            pass
        try:
            StopThreading.stop_thread(self.sever_th)
        except Exception:
            pass
```

- **功能**：关闭 UDP 套接字并停止监听线程。
- **说明**：关闭套接字并停止线程，确保资源释放。
